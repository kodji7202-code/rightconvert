# Contributing to RightConvert

RightConvert is MIT licensed. Contributions (code, documentation and tests)
are welcome via issues and pull requests.

1. Open an issue for substantial new functionality.
2. Fork the repository, create a descriptive branch and make one focused change.
3. Run `python -m pytest -q` on Windows; attach a reproduction/test with fixes.
4. Avoid committing build folders, generated installers, personal test documents,
   private signing keys, account credentials or customer data.
5. Contributions must be your own work or include compatible attribution and
   third-party license notices.

By submitting a contribution you agree that your original contribution is
made available under the repository's MIT license, without overriding the
licenses of third-party dependencies.
