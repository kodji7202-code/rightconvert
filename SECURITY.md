# Security Policy

Please report suspected vulnerabilities privately to
**kodji7202@gmail.com**, subject: `RightConvert security`.

Include affected version, environment, short reproduction instructions and
the possible impact. Do not send sensitive customer documents, secrets or
private system files as attachments. Please allow reasonable time for a fix
before publishing exploit details.

RightConvert performs local conversion of potentially untrusted image,
media, PDF and Office input. Use separate disposable fixtures for security
tests, keep Windows and dependencies updated, and do not disable endpoint
protection to install an unsigned build.
